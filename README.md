# BloxClicker v1.0

🎮 **BloxClicker** is a lightweight automation tool for Roblox – specifically designed for the game **Blox Fruits**.  
It includes features to reduce grind and boost gameplay efficiency.

---

## 🚀 Features
- ⚡ **Auto Clicker** – continuously clicks at a customizable speed
- 🖱️ **Left-click Hold Repeater** – hold down left mouse and it rapidly repeats clicks
- 🔁 **Q-key Repeater** – repeatedly sends the "Q" key while held
- 👀 **Mini Overlay** – a small status window that follows the Roblox window
- 🎯 **Game-Aware Activation** – macros only run while Roblox is focused

## 🔒 Safety
This program is made with [AutoHotkey v2](https://www.autohotkey.com/) and is **100% safe to use**.  
Some browsers or Windows SmartScreen may warn you because the app automates input and is unsigned.

✅ You can scan the ZIP file with [VirusTotal](https://virustotal.com/) for peace of mind.  
🛠 Make sure to **unzip** the file before running the program.

---

## 📖 Instructions
1. Download the ZIP file below  
2. Unzip it to a folder of your choice  
3. Launch `BloxClicker.exe`  
4. Use the simple GUI to enable the features you want  

ℹ️ Roblox must be running and in focus for macros to activate.
