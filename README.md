# BloxClicker

🎮 **BloxClicker** is an automation tool for the game **Blox Fruits** on Roblox. It includes features like auto-clicking, Q-key repeater, and a mini overlay to enhance gameplay.

## Features
- ⚡ Auto Clicker with adjustable speed
- 🖱️ Left-click Hold Repeater
- 🔁 Q-key Repeater
- 👀 Mini Overlay showing status

## Installation

To run BloxClicker, you need [AutoHotkey v2](https://www.autohotkey.com/).

1. Clone or download the repository.
2. Unzip the files to a folder.
3. Run `BloxClicker.exe`.

## How to Use

Once the program is launched:
- Select the features you want to enable using the simple GUI.
