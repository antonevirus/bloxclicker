# BloxClicker

🎮 **BloxClicker** is an automation tool for the game **Blox Fruits** on Roblox. It includes features like auto-clicking, Q-key repeater, and a mini overlay to enhance gameplay.

## Features
- ⚡ **Auto Clicker** with adjustable speed
- 🖱️ **Left-click Hold Repeater** for rapid clicking
- 🔁 **Q-key Repeater** for skill spamming
- 👀 **Mini Overlay** showing status of active features

## Installation

To run **BloxClicker**, simply download the ZIP file and unzip it to a folder.  
You do **not need to install AutoHotkey** as it is already compiled into the `BloxClicker.exe` file.

1. Download the latest release from the [Releases](https://github.com/yourusername/BloxClicker/releases) page.
2. Unzip the downloaded file to any folder.
3. Double-click `BloxClicker.exe` to launch the program.

## How to Use

Once **BloxClicker** is launched:
- The program’s GUI will let you enable the features you need (auto-clicker, Q-key repeater, etc.).
- **Roblox** needs to be running for the overlay and macros to work properly.
